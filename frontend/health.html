🛠️ Soluciones para "Failed to fetch"

Problema de CORS: El servidor podría no estar configurado para aceptar peticiones desde tu dominio.
Servidor caído: El servidor de Railway podría estar temporalmente fuera de servicio.
Bloqueo de red: Tu firewall, antivirus o red corporativa podría estar bloqueando la conexión.
Dominio incorrecto: Verifica que la URL de la API sea correcta.
Problema de DNS: Intenta usar la IP directa del servidor si está disponible.
